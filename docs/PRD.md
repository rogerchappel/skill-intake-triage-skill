# PRD

## Problem

Intake triage reduces accidental skill misuse by making match rationale, missing inputs, and side-effect boundaries visible before a run starts.

## Users

Agent builders, OSS maintainers, and operators who need local evidence before a run proceeds.

## MVP Scope

- Local-first CLI
- Library API
- Fixture-backed tests
- Smoke command
- Skill instructions

## Non-Goals

- Live connector writes
- Hosted service
- Package publishing
- Automatic approvals
